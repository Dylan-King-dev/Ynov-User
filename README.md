# Ynov User

Ynov User est une application React qui permet de :

- voir une liste de recettes ;
- consulter le détail d'une recette ;
- voir la liste des utilisateurs ;
- consulter le profil d'un utilisateur ;
- se connecter avec un nom d'utilisateur et un mot de passe présents dans `users.json`.

## Lancer le projet

Il faut avoir Node.js installé.

Dans un terminal, place-toi dans le dossier du projet :

```bash
cd ynov-user
```

Installe les dépendances :

```bash
npm install
```

Lance le serveur de développement :

```bash
npm run dev
```

Vite donnera une adresse, généralement :

```text
http://localhost:5173
```

Ouvre cette adresse dans ton navigateur.

## Autres commandes

Vérifier que le projet compile :

```bash
npm run build
```

Vérifier le code avec le linter :

```bash
npm run lint
```
